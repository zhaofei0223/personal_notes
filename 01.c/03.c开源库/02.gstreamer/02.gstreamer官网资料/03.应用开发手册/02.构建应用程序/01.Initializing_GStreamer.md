# 初始化 GStreamer

编写 GStreamer 应用程序时，只需包含gst/gst.h 相应的库文件即可访问库函数。除此之外，还需要初始化 GStreamer 库。

## 简单初始化

在使用 GStreamer 库之前，gst_init必须从主应用程序中调用该库。此调用将执行必要的库初始化操作，并解析 GStreamer 特有的命令行选项。

一个典型的程序[1]会包含如下所示的初始化 GStreamer 的代码：

```c
#include <stdio.h>
#include <gst/gst.h>

int
main (int   argc,
      char *argv[])
{
  const gchar *nano_str;
  guint major, minor, micro, nano;

  gst_init (&argc, &argv);

  gst_version (&major, &minor, &micro, &nano);

  if (nano == 1)
    nano_str = "(CVS)";
  else if (nano == 2)
    nano_str = "(Prerelease)";
  else
    nano_str = "";

  printf ("This program is linked against GStreamer %d.%d.%d %s\n",
          major, minor, micro, nano_str);

  return 0;
}
```

使用GST_VERSION_MAJOR` GStreamer_version`GST_VERSION_MINOR和GST_VERSION_MICRO `GStreamer_version` 宏可以获取您正在构建的 GStreamer 版本，或者使用 `GStreamer_version` 函数gst_version可以获取您的应用程序链接的版本。GStreamer 目前采用的方案是，主版本号和次版本号相同的版本在 API 和 ABI 上是兼容的。

也可以使用gst_init两个NULL 参数调用该函数，在这种情况下，GStreamer 将不会解析任何命令行选项。

## GOption接口

您还可以使用GOption表格来初始化自己的参数，如下例所示：

```c
#include <stdio.h>
#include <gst/gst.h>

int
main (int   argc,
      char *argv[])
{
  gboolean silent = FALSE;
  gchar *savefile = NULL;
  GOptionContext *ctx;
  GError *err = NULL;
  GOptionEntry entries[] = {
    { "silent", 's', 0, G_OPTION_ARG_NONE, &silent,
      "do not output status information", NULL },
    { "output", 'o', 0, G_OPTION_ARG_STRING, &savefile,
      "save xml representation of pipeline to FILE and exit", "FILE" },
    { NULL }
  };

  ctx = g_option_context_new ("- Your application");
  g_option_context_add_main_entries (ctx, entries, NULL);
  g_option_context_add_group (ctx, gst_init_get_option_group ());
  if (!g_option_context_parse (ctx, &argc, &argv, &err)) {
    g_print ("Failed to initialize: %s\n", err->message);
    g_clear_error (&err);
    g_option_context_free (ctx);
    return 1;
  }
  g_option_context_free (ctx);

  printf ("Run me with --help to see the Application options appended.\n");

  return 0;
}
```

如本片段所示，您可以使用 GOption 表来定义特定于应用程序的命令行选项，并将此表与函数返回的选项组一起传递给 GLib 初始化函数gst_init_get_option_group。除了标准的 GStreamer 选项之外，您的应用程序选项也将被解析。

本示例的代码是从文档中自动提取的，并构建tests/examples/manual在 GStreamer tarball 中。
