# Metadata

GStreamer 明确区分了它支持的两种元数据类型：流标签（Stream tags）和流信息（Stream-info）。流标签以非技术性的方式描述流的内容；而流信息则以较为技术性的方式描述流的属性。流标签的示例包括歌曲的作者、歌曲标题或歌曲所属专辑。流信息的示例包括视频大小、音频采样率、使用的编解码器等等。

GstPad标签使用 GStreamer 标签系统进行处理。可以通过获取该 pad 的当前（协商的）流信息来检索流信息GstCaps。

## Metadata reading

最简便的获取流信息的方式是从数据块中读取GstPad。请注意，这需要访问所有包含所需流信息的数据块。这种方法已在“使用元数据功能”一节中讨论过，因此本文不再赘述。

在 GStreamer 中，标签读取是通过总线实现的。您可以监听 GST_MESSAGE_TAG消息并根据需要进行处理。这在之前的“总线”部分已经讨论过。

请注意，该GST_MESSAGE_TAG消息可能会多次发出，应用程序有责任以一致的方式聚合和显示这些标签。这可以通过以下方式实现：gst_tag_list_merge ()加载新歌曲时，或在收听网络电台时每隔几分钟清空缓存。此外，请确保使用GST_TAG_MERGE_PREPEND合并模式，以便新标题（后添加的标题）优先于旧标题。

以下示例展示了如何从文件中提取标签并打印出来：

```c
/* compile with:
 * gcc -o tags tags.c `pkg-config --cflags --libs gstreamer-1.0` */
#include <gst/gst.h>

static void
print_one_tag (const GstTagList * list, const gchar * tag, gpointer user_data)
{
  int i, num;

  num = gst_tag_list_get_tag_size (list, tag);
  for (i = 0; i < num; ++i) {
    const GValue *val;

    /* Note: when looking for specific tags, use the gst_tag_list_get_xyz() API,
     * we only use the GValue approach here because it is more generic */
    val = gst_tag_list_get_value_index (list, tag, i);
    if (G_VALUE_HOLDS_STRING (val)) {
      g_print ("\t%20s : %s\n", tag, g_value_get_string (val));
    } else if (G_VALUE_HOLDS_UINT (val)) {
      g_print ("\t%20s : %u\n", tag, g_value_get_uint (val));
    } else if (G_VALUE_HOLDS_DOUBLE (val)) {
      g_print ("\t%20s : %g\n", tag, g_value_get_double (val));
    } else if (G_VALUE_HOLDS_BOOLEAN (val)) {
      g_print ("\t%20s : %s\n", tag,
          (g_value_get_boolean (val)) ? "true" : "false");
    } else if (GST_VALUE_HOLDS_BUFFER (val)) {
      GstBuffer *buf = gst_value_get_buffer (val);
      guint buffer_size = gst_buffer_get_size (buf);

      g_print ("\t%20s : buffer of size %u\n", tag, buffer_size);
    } else if (GST_VALUE_HOLDS_DATE_TIME (val)) {
      GstDateTime *dt = g_value_get_boxed (val);
      gchar *dt_str = gst_date_time_to_iso8601_string (dt);

      g_print ("\t%20s : %s\n", tag, dt_str);
      g_free (dt_str);
    } else {
      g_print ("\t%20s : tag of type '%s'\n", tag, G_VALUE_TYPE_NAME (val));
    }
  }
}

static void
on_new_pad (GstElement * dec, GstPad * pad, GstElement * fakesink)
{
  GstPad *sinkpad;

  sinkpad = gst_element_get_static_pad (fakesink, "sink");
  if (!gst_pad_is_linked (sinkpad)) {
    if (gst_pad_link (pad, sinkpad) != GST_PAD_LINK_OK)
      g_error ("Failed to link pads!");
  }
  gst_object_unref (sinkpad);
}

int
main (int argc, char ** argv)
{
  GstElement *pipe, *dec, *sink;
  GstMessage *msg;
  gchar *uri;

  gst_init (&argc, &argv);

  if (argc < 2)
    g_error ("Usage: %s FILE or URI", argv[0]);

  if (gst_uri_is_valid (argv[1])) {
    uri = g_strdup (argv[1]);
  } else {
    uri = gst_filename_to_uri (argv[1], NULL);
  }

  pipe = gst_pipeline_new ("pipeline");

  dec = gst_element_factory_make ("uridecodebin", NULL);
  g_object_set (dec, "uri", uri, NULL);
  gst_bin_add (GST_BIN (pipe), dec);

  sink = gst_element_factory_make ("fakesink", NULL);
  gst_bin_add (GST_BIN (pipe), sink);

  g_signal_connect (dec, "pad-added", G_CALLBACK (on_new_pad), sink);

  gst_element_set_state (pipe, GST_STATE_PAUSED);

  while (TRUE) {
    GstTagList *tags = NULL;

    msg = gst_bus_timed_pop_filtered (GST_ELEMENT_BUS (pipe),
        GST_CLOCK_TIME_NONE,
        GST_MESSAGE_ASYNC_DONE | GST_MESSAGE_TAG | GST_MESSAGE_ERROR);

    if (GST_MESSAGE_TYPE (msg) != GST_MESSAGE_TAG) /* error or async_done */
      break;

    gst_message_parse_tag (msg, &tags);

    g_print ("Got tags from element %s:\n", GST_OBJECT_NAME (msg->src));
    gst_tag_list_foreach (tags, print_one_tag, NULL);
    g_print ("\n");
    gst_tag_list_unref (tags);

    gst_message_unref (msg);
  }

  if (GST_MESSAGE_TYPE (msg) == GST_MESSAGE_ERROR) {
    GError *err = NULL;

    gst_message_parse_error (msg, &err, NULL);
    g_printerr ("Got error: %s\n", err->message);
    g_error_free (err);
  }

  gst_message_unref (msg);
  gst_element_set_state (pipe, GST_STATE_NULL);
  gst_object_unref (pipe);
  g_free (uri);
  return 0;
}
```

## Tag writing

标签编写是通过 GstTagSetter 界面完成的。你只需要在流程中添加一个支持标签集的元素即可。

要查看管道中的任何元素是否支持标签写入，可以使用该函数gst_bin_iterate_all_by_interface (pipeline, GST_TYPE_TAG_SETTER)。对于结果元素（通常是编码器或复用器），可以使用 gst_tag_setter_merge_tags ()标签列表或gst_tag_setter_add_tags () 单个标签来设置标签。

GStreamer 标签支持的一个很棒的附加功能是，标签会在管道中保留。这意味着，如果您将一个包含标签的文件转码为另一种支持标签的媒体类型，那么这些标签将作为数据流的一部分进行处理，并合并到新写入的媒体文件中。
