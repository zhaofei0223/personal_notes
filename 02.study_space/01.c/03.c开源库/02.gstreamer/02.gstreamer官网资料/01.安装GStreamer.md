# 安装GStreamer

官网资料文档链接：

[https://gstreamer.freedesktop.org/documentation/?gi-language=c](https://gstreamer.freedesktop.org/documentation/?gi-language=c)

<br>

**GStreamer**：一个灵活、快速且跨平台的多媒体框架

GStreamer 是一个功能极其强大且用途广泛的流媒体应用程序开发框架。GStreamer 框架的许多优点都源于其模块化设计：它可以无缝集成新的插件模块。但由于模块化和强大的功能往往伴随着更高的复杂性，因此编写新的应用程序并非易事。

<br>

**在 Ubuntu 或 Debian 上安装 GStreamer**

运行以下命令：

官网指令：

```shell
apt-get install libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libgstreamer-plugins-bad1.0-dev gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad gstreamer1.0-plugins-ugly gstreamer1.0-libav gstreamer1.0-tools gstreamer1.0-x gstreamer1.0-alsa gstreamer1.0-gl gstreamer1.0-gtk3 gstreamer1.0-qt5 gstreamer1.0-pulseaudio
```

整理后的指令：

```shell
sudo apt update -y
sudo apt install libgstreamer1.0-dev -y
sudo apt install libgstreamer-plugins-base1.0-dev -y 
sudo apt install libgstreamer-plugins-bad1.0-dev -y
sudo apt install gstreamer1.0-plugins-base -y
sudo apt install gstreamer1.0-plugins-good -y
sudo apt install gstreamer1.0-plugins-bad -y
sudo apt install gstreamer1.0-plugins-ugly -y
sudo apt install gstreamer1.0-libav -y
sudo apt install gstreamer1.0-tools -y
sudo apt install gstreamer1.0-x -y
sudo apt install gstreamer1.0-alsa -y
sudo apt install gstreamer1.0-gl -y
sudo apt install gstreamer1.0-gtk3 -y
sudo apt install gstreamer1.0-qt5 -y
```

整理成一条后的指令：

```shell
sudo apt update -y && sudo apt install libgstreamer1.0-dev -y && sudo apt install libgstreamer-plugins-base1.0-dev -y && sudo apt install libgstreamer-plugins-bad1.0-dev -y && sudo apt install gstreamer1.0-plugins-base -y && sudo apt install gstreamer1.0-plugins-good -y && sudo apt install gstreamer1.0-plugins-bad -y && sudo apt install gstreamer1.0-plugins-ugly -y && sudo apt install gstreamer1.0-libav -y && sudo apt install gstreamer1.0-tools -y && sudo apt install gstreamer1.0-x -y && sudo apt install gstreamer1.0-alsa -y &&  sudo apt install gstreamer1.0-gl -y && sudo apt install gstreamer1.0-gtk3 -y && sudo apt install gstreamer1.0-qt5 -y && sudo apt install gstreamer1.0-pulseaudio -y
```

**使用 GStreamer 构建应用程序**

除此之外，还需要一个gcc编译器和一个文本编辑器作为“开发环境”。要编译需要 GStreamer 并使用 GStreamer 核心库的代码，请记住在gcc命令中添加以下字符串：

```shell
pkg-config --cflags --libs gstreamer-1.0
```

如果您使用的是其他 GStreamer 库，例如视频库，则必须在上面的字符串中的 gstreamer-1.0 之后添加其他软件包（例如，视频库需要添加 gstreamer-video-1.0）。

如果您的应用程序是借助 libtool 构建的，例如使用 automake/autoconf 作为构建系统时，您必须configure从gst-sdk-shell环境内部运行脚本。

**构建教程**

切换到目录查找 basic-tutorials-1：

```shell
cd gstreamer/subprojects/gst-docs/examples/tutorials/
```

然后使用以下命令编译：

```shell
gcc basic-tutorial-1.c -o basic-tutorial-1 `pkg-config --cflags --libs gstreamer-1.0`
```

使用您感兴趣的教程的文件名（basic-tutorial-1在本例中）。

> 警告根据您需要使用的 GStreamer 库，您可能需要在pkg-config命令中添加其他包。此外，gstreamer-1.0 在每个教程的源代码底部，您都可以找到该教程的命令，其中包含所需的库及其顺序。在开发您自己的应用程序时，GStreamer 文档会告诉您每个函数属于哪个库。

<br>

**运行教程**

要运行教程，只需执行所需的教程即可：

```shell
./basic-tutorial-1
```
