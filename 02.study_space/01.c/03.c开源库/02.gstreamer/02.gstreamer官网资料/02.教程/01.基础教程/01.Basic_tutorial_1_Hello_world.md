## 你好世界

将此代码复制到名为（或在您的 GStreamer 安装目录中查找）的文本文件中。basic-tutorial-1.c

基础教程-1.c

```c
#include <gst/gst.h>

#ifdef __APPLE__
#include <TargetConditionals.h>
#endif

int
tutorial_main (int argc, char *argv[])
{
  GstElement *pipeline;
  GstBus *bus;
  GstMessage *msg;

  /* Initialize GStreamer */
  gst_init (&argc, &argv);

  /* Build the pipeline */
  pipeline =
      gst_parse_launch
      ("playbin uri=https://gstreamer.freedesktop.org/data/media/sintel_trailer-480p.webm",
      NULL);

  /* Start playing */
  gst_element_set_state (pipeline, GST_STATE_PLAYING);

  /* Wait until error or EOS */
  bus = gst_element_get_bus (pipeline);
  msg =
      gst_bus_timed_pop_filtered (bus, GST_CLOCK_TIME_NONE,
      GST_MESSAGE_ERROR | GST_MESSAGE_EOS);

  /* See next tutorial for proper error message handling/parsing */
  if (GST_MESSAGE_TYPE (msg) == GST_MESSAGE_ERROR) {
    g_printerr ("An error occurred! Re-run with the GST_DEBUG=*:WARN "
        "environment variable set for more details.\n");
  }

  /* Free resources */
  gst_message_unref (msg);
  gst_object_unref (bus);
  gst_element_set_state (pipeline, GST_STATE_NULL);
  gst_object_unref (pipeline);
  return 0;
}

int
main (int argc, char *argv[])
{
#if defined(__APPLE__) && TARGET_OS_MAC && !TARGET_OS_IPHONE
  return gst_macos_main ((GstMainFunc) tutorial_main, argc, argv, NULL);
#else
  return tutorial_main (argc, argv);
#endif
}
```

请按照“在 Linux 上安装”、“在 Mac OS X 上安装”或“在 Windows 上安装”中的说明进行编译。如果出现编译错误，请仔细检查这些章节中的说明。

如果一切编译成功，运行可执行文件！你应该会看到一个窗口弹出，其中包含一个直接从互联网播放的视频，并配有音频。恭喜！

本教程会打开一个窗口并播放一段视频，同时播放音频。由于媒体文件来自互联网，窗口可能需要几秒钟才能显示，具体时间取决于您的网络连接速度。此外，本教程没有延迟管理（缓冲），因此在网络连接速度较慢的情况下，视频可能会在几秒钟后停止播放。请参阅基础教程 12：流媒体播放，了解此问题的解决方案。

## 攻略

让我们来看一下这些代码，看看它们的作用：

```c
  /* Initialize GStreamer */
  gst_init (&argc, &argv);
```

这必须始终是你的第一个 GStreamer 命令。此外， gst_init ():

- 初始化所有内部结构

- 检查有哪些插件可用。

- 执行任何适用于 GStreamer 的命令行选项

如果您始终将命令行参数传递 argc给argvgst_init ( )，您的应用程序将自动受益于 GStreamer 标准命令行选项（有关此内容的更多信息，请参阅基础教程 10：GStreamer 工具）。

```c
  /* Build the pipeline */
  pipeline =
      gst_parse_launch
      ("playbin uri=https://gstreamer.freedesktop.org/data/media/sintel_trailer-480p.webm",
      NULL);
```

这一行是本教程的核心，并举例说明了两个关键点：gst_parse_launch () 和playbin。

### gst_parse_launch

GStreamer 是一个用于处理多媒体流的框架。媒体数据从“源”元素（生产者）流向“汇”元素（消费者），途中会经过一系列执行各种任务的中间元素。所有相互连接的元素集合称为“管道”。

在 GStreamer 中，通常通过手动组装各个元素来构建管道，但是，当管道足够简单，并且不需要任何高级功能时，可以使用快捷方式： gst_parse_launch ()。

这个函数接受管道的文本表示形式，并将其转换为实际的管道，非常方便。事实上，这个函数非常方便，以至于有一个完全围绕它构建的工具，你会非常熟悉它（请参阅基础教程 10：GStreamer 工具，了解 gst-launch - 1.0及其 语法）。

### playbin

那么，我们要求gst_parse_launch () 为我们构建什么样的管道呢？这里就引出了第二个关键点：我们正在构建一个由名为playbin的单个元素组成的管道。

playbin是一个特殊的元素，它既是源又是接收器，构成了一个完整的管道。它在内部创建并连接播放媒体所需的所有元素，因此您无需担心这些细节。

它虽然无法像手动流程那样实现精细的控制，但仍然提供了足够的自定义选项，足以满足各种应用需求，包括本教程。

在这个例子中，我们只向playbin传递了一个参数，即我们要播放的媒体的 URI。尝试将其更改为其他内容！无论是 URIhttp://还是其他file://URI，playbin都会透明地实例化相应的 GStreamer 源！

如果 URI 输入错误、文件不存在或缺少插件，GStreamer 提供了几种通知机制，但本示例中我们只在出错时退出，所以不要期望得到太多反馈。

```c
  /* Start playing */
  gst_element_set_state (pipeline, GST_STATE_PLAYING);
```

这句话引出了另一个有趣的概念：状态。每个 GStreamer 元素都有一个关联的状态，你可以把它想象成普通 DVD 播放器上的播放/暂停按钮。目前，只需记住，除非你将管道设置为相应的状态，否则播放不会开始PLAYING。

在这一行中，gst_element_set_state () 将pipeline（我们唯一的元素，记住）设置为PLAYING状态，从而启动播放。

```c
  /* Wait until error or EOS */
  bus = gst_element_get_bus (pipeline);
  msg =
      gst_bus_timed_pop_filtered (bus, GST_CLOCK_TIME_NONE,
      GST_MESSAGE_ERROR | GST_MESSAGE_EOS);
```

这些代码行会一直等待，直到发生错误或到达流的末尾。`gst_element_get_bus () `用于获取管道的总线，而 `gst_bus_timed_pop_filtered ()` 会阻塞，直到通过该总线收到 ERROR 或EOS流结束信号。不必过于担心这行代码，GStreamer 总线的相关内容在基础教程 2：GStreamer 概念中有详细解释。

就这样！从现在开始，GStreamer 会处理一切。当媒体文件播放完毕（EOS）或遇到错误（例如关闭视频窗口或拔掉网线）时，程序将停止运行。您也可以随时在控制台中按下 Ctrl+C 来停止程序。

### Cleanup

不过，在终止应用程序之前，我们还需要做一些事情来妥善清理工作。

```c
  /* Free resources */
  gst_message_unref (msg);
  gst_object_unref (bus);
  gst_element_set_state (pipeline, GST_STATE_NULL);
  gst_object_unref (pipeline);
  return 0;
```

务必阅读所用函数的文档，以了解使用后是否应该释放它们返回的对象。

在这种情况下，gst_bus_timed_pop_filtered () 返回了一条消息，需要使用gst_message_unref () 释放该消息（有关消息的更多信息，请参阅 基础教程 2：GStreamer 概念）。

`gst_element_get_bus ()` 添加了对总线的引用，该引用必须使用`gst_object_unref ()` 释放。将管道设置为 NULL 状态可确保其释放所有已分配的资源（有关状态的更多信息，请参阅 基础教程 3：动态管道）。最后，取消对管道的引用将销毁它及其所有内容。
