# 基础教程 13：播放速度

## 目标

快进、倒放和慢动作都是统称为“特效模式”的技术，它们的共同点是都会改变正常的播放速度。本教程将展示如何实现这些效果，并在此基础上加入逐帧播放功能。具体来说，本教程将演示：

- 如何改变播放速度，比正常速度更快或更慢，以及快进和慢退。
- 如何逐帧播放视频

## 介绍

快进是指以高于正常（预期）速度的速度播放媒体；而慢动作则使用低于预期速度的速度播放。倒放则与之类似，只是播放方向相反，从视频流的结尾播放到开头。

所有这些技术所做的只是改变播放速率，播放速率是一个变量，正常播放时等于 1.0，快模式下大于 1.0（绝对值），慢模式下小于 1.0（绝对值），正向播放时为正，反向播放时为负。

GStreamer 提供了两种改变播放速率的机制：步进事件和跳转事件。步进事件允许跳过指定长度的媒体，并改变后续的播放速率（只能设置为正值）。跳转事件则允许跳转到流中的任意位置，并设置正负播放速率。

在基础教程 4：时间管理中，我们已经介绍了查找事件，并使用辅助函数隐藏了其复杂性。本教程将更详细地解释如何使用这些事件。

由于创建步进事件所需的参数较少，因此步进事件是更改播放速度的一种更便捷的方式；然而，步进事件也存在一些缺点，因此本教程中将使用寻址事件。步进事件仅影响管道末端的接收器（sink），因此只有当管道的其余部分支持以不同的速度运行时，步进事件才能正常工作。寻址事件则会贯穿整个管道，因此每个元素都可以对其做出反应。步进事件的优点是响应速度更快。此外，步进事件无法更改播放方向。

要使用这些事件，需要先创建它们，然后将它们传递到管道中，管道中的事件会向上游传播，直到到达能够处理它们的元素。如果将事件传递给类似 `<bin>` 的元素，它会将事件简单地传递给其所有接收器，这将导致执行多次查找操作。常见的做法是通过 `<bin>` 的 `sink`或 ` sink` 属性playbin检索 `<bin>` 的某个接收器，并将事件直接传递给该接收器。playbinvideo-sinkaudio-sink

逐帧播放是一种允许逐帧播放视频的技术。它的实现方式是暂停视频流水线，然后发送步进事件，每次跳过一帧。

基础教程-13.c

```c
#include <string.h>
#include <stdio.h>
#include <gst/gst.h>

#ifdef __APPLE__
#include <TargetConditionals.h>
#endif

typedef struct _CustomData
{
  GstElement *pipeline;
  GstElement *video_sink;
  GMainLoop *loop;

  gboolean playing;             /* Playing or Paused */
  gdouble rate;                 /* Current playback rate (can be negative) */
} CustomData;

/* Send seek event to change rate */
static void
send_seek_event (CustomData * data)
{
  gint64 position;
  GstEvent *seek_event;

  /* Obtain the current position, needed for the seek event */
  if (!gst_element_query_position (data->pipeline, GST_FORMAT_TIME, &position)) {
    g_printerr ("Unable to retrieve current position.\n");
    return;
  }

  /* Create the seek event */
  if (data->rate > 0) {
    seek_event =
        gst_event_new_seek (data->rate, GST_FORMAT_TIME,
        GST_SEEK_FLAG_FLUSH | GST_SEEK_FLAG_ACCURATE, GST_SEEK_TYPE_SET,
        position, GST_SEEK_TYPE_END, 0);
  } else {
    seek_event =
        gst_event_new_seek (data->rate, GST_FORMAT_TIME,
        GST_SEEK_FLAG_FLUSH | GST_SEEK_FLAG_ACCURATE, GST_SEEK_TYPE_SET, 0,
        GST_SEEK_TYPE_SET, position);
  }

  if (data->video_sink == NULL) {
    /* If we have not done so, obtain the sink through which we will send the seek events */
    g_object_get (data->pipeline, "video-sink", &data->video_sink, NULL);
  }

  /* Send the event */
  gst_element_send_event (data->video_sink, seek_event);

  g_print ("Current rate: %g\n", data->rate);
}

/* Process keyboard input */
static gboolean
handle_keyboard (GIOChannel * source, GIOCondition cond, CustomData * data)
{
  gchar *str = NULL;

  if (g_io_channel_read_line (source, &str, NULL, NULL,
          NULL) != G_IO_STATUS_NORMAL) {
    return TRUE;
  }

  switch (g_ascii_tolower (str[0])) {
    case 'p':
      data->playing = !data->playing;
      gst_element_set_state (data->pipeline,
          data->playing ? GST_STATE_PLAYING : GST_STATE_PAUSED);
      g_print ("Setting state to %s\n", data->playing ? "PLAYING" : "PAUSE");
      break;
    case 's':
      if (g_ascii_isupper (str[0])) {
        data->rate *= 2.0;
      } else {
        data->rate /= 2.0;
      }
      send_seek_event (data);
      break;
    case 'd':
      data->rate *= -1.0;
      send_seek_event (data);
      break;
    case 'n':
      if (data->video_sink == NULL) {
        /* If we have not done so, obtain the sink through which we will send the step events */
        g_object_get (data->pipeline, "video-sink", &data->video_sink, NULL);
      }

      gst_element_send_event (data->video_sink,
          gst_event_new_step (GST_FORMAT_BUFFERS, 1, ABS (data->rate), TRUE,
              FALSE));
      g_print ("Stepping one frame\n");
      break;
    case 'q':
      g_main_loop_quit (data->loop);
      break;
    default:
      break;
  }

  g_free (str);

  return TRUE;
}

int
tutorial_main (int argc, char *argv[])
{
  CustomData data;
  GstStateChangeReturn ret;
  GIOChannel *io_stdin;

  /* Initialize GStreamer */
  gst_init (&argc, &argv);

  /* Initialize our data structure */
  memset (&data, 0, sizeof (data));

  /* Print usage map */
  g_print ("USAGE: Choose one of the following options, then press enter:\n"
      " 'P' to toggle between PAUSE and PLAY\n"
      " 'S' to increase playback speed, 's' to decrease playback speed\n"
      " 'D' to toggle playback direction\n"
      " 'N' to move to next frame (in the current direction, better in PAUSE)\n"
      " 'Q' to quit\n");

  /* Build the pipeline */
  data.pipeline =
      gst_parse_launch
      ("playbin uri=https://gstreamer.freedesktop.org/data/media/sintel_trailer-480p.webm",
      NULL);

  /* Add a keyboard watch so we get notified of keystrokes */
#ifdef G_OS_WIN32
  io_stdin = g_io_channel_win32_new_fd (fileno (stdin));
#else
  io_stdin = g_io_channel_unix_new (fileno (stdin));
#endif
  g_io_add_watch (io_stdin, G_IO_IN, (GIOFunc) handle_keyboard, &data);

  /* Start playing */
  ret = gst_element_set_state (data.pipeline, GST_STATE_PLAYING);
  if (ret == GST_STATE_CHANGE_FAILURE) {
    g_printerr ("Unable to set the pipeline to the playing state.\n");
    gst_object_unref (data.pipeline);
    return -1;
  }
  data.playing = TRUE;
  data.rate = 1.0;

  /* Create a GLib Main Loop and set it to run */
  data.loop = g_main_loop_new (NULL, FALSE);
  g_main_loop_run (data.loop);

  /* Free resources */
  g_main_loop_unref (data.loop);
  g_io_channel_unref (io_stdin);
  gst_element_set_state (data.pipeline, GST_STATE_NULL);
  if (data.video_sink != NULL)
    gst_object_unref (data.video_sink);
  gst_object_unref (data.pipeline);
  return 0;
}

int
main (int argc, char *argv[])
{
#if defined(__APPLE__) && TARGET_OS_MAC && !TARGET_OS_IPHONE
  return gst_macos_main ((GstMainFunc) tutorial_main, argc, argv, NULL);
#else
  return tutorial_main (argc, argv);
#endif
}
```

此函数创建一个新的寻址事件并将其发送到管道以更新速率。首先，使用 `get_location()` 函数恢复当前位置 gst_element_query_position()。这是必要的，因为寻址事件会跳转到流中的另一个位置，而我们实际上并不想移动，所以跳转到当前位置。使用步进事件会更简单，但如引言中所述，该事件目前尚未完全实现。

寻道事件是通过以下方式创建的gst_event_new_seek()。其参数主要包括新的播放速率、新的起始位置和新的停止位置。无论播放方向如何，起始位置都必须小于停止位置，因此两个播放方向的处理方式不同。
