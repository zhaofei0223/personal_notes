# 播放教程 6：音频可视化

## 目标

GStreamer 提供了一系列可以将音频转换为视频的元素。例如，它们可以用于科学可视化，或者为音乐播放器增添趣味性。本教程将展示：

- 如何启用音频可视化
- 如何选择可视化元素

## 介绍

启用音频可视化playbin其实非常简单。只需设置相应的playbin标志，当检测到纯音频流时，它就会实例化必要的元素来创建和显示可视化效果。

如果要指定用于生成可视化的实际元素，则需要自行实例化该元素，然后 playbin通过vis-plugin属性进行指定。

本教程会在 GStreamer 注册表中搜索 Visualization 类的所有元素，尝试选择goom其中一个（如果该元素不可用，则选择另一个），并将其传递给playbin。

## 一款高级音乐播放器

将此代码复制到名为 . 的文本文件中playback-tutorial-6.c。

播放教程-6.c

```c
#include <gst/gst.h>

#ifdef __APPLE__
#include <TargetConditionals.h>
#endif

/* playbin2 flags */
typedef enum
{
  GST_PLAY_FLAG_VIS = (1 << 3)  /* Enable rendering of visualizations when there is no video stream. */
} GstPlayFlags;

/* Return TRUE if this is a Visualization element */
static gboolean
filter_vis_features (GstPluginFeature * feature, gpointer data)
{
  GstElementFactory *factory;

  if (!GST_IS_ELEMENT_FACTORY (feature))
    return FALSE;
  factory = GST_ELEMENT_FACTORY (feature);
  if (!g_strrstr (gst_element_factory_get_klass (factory), "Visualization"))
    return FALSE;

  return TRUE;
}

int
tutorial_main (int argc, char *argv[])
{
  GstElement *pipeline, *vis_plugin;
  GstBus *bus;
  GstMessage *msg;
  GList *list, *walk;
  GstElementFactory *selected_factory = NULL;
  guint flags;

  /* Initialize GStreamer */
  gst_init (&argc, &argv);

  /* Get a list of all visualization plugins */
  list =
      gst_registry_feature_filter (gst_registry_get (), filter_vis_features,
      FALSE, NULL);

  /* Print their names */
  g_print ("Available visualization plugins:\n");
  for (walk = list; walk != NULL; walk = g_list_next (walk)) {
    const gchar *name;
    GstElementFactory *factory;

    factory = GST_ELEMENT_FACTORY (walk->data);
    name = gst_element_factory_get_longname (factory);
    g_print ("  %s\n", name);

    if (selected_factory == NULL || g_str_has_prefix (name, "GOOM")) {
      selected_factory = factory;
    }
  }

  /* Don't use the factory if it's still empty */
  /* e.g. no visualization plugins found */
  if (!selected_factory) {
    g_print ("No visualization plugins found!\n");
    return -1;
  }

  /* We have now selected a factory for the visualization element */
  g_print ("Selected '%s'\n",
      gst_element_factory_get_longname (selected_factory));
  vis_plugin = gst_element_factory_create (selected_factory, NULL);
  if (!vis_plugin)
    return -1;

  /* Build the pipeline */
  pipeline =
      gst_parse_launch ("playbin uri=http://radio.hbr1.com:19800/ambient.ogg",
      NULL);

  /* Set the visualization flag */
  g_object_get (pipeline, "flags", &flags, NULL);
  flags |= GST_PLAY_FLAG_VIS;
  g_object_set (pipeline, "flags", flags, NULL);

  /* set vis plugin for playbin2 */
  g_object_set (pipeline, "vis-plugin", vis_plugin, NULL);

  /* Start playing */
  gst_element_set_state (pipeline, GST_STATE_PLAYING);

  /* Wait until error or EOS */
  bus = gst_element_get_bus (pipeline);
  msg =
      gst_bus_timed_pop_filtered (bus, GST_CLOCK_TIME_NONE,
      GST_MESSAGE_ERROR | GST_MESSAGE_EOS);

  /* Free resources */
  if (msg != NULL)
    gst_message_unref (msg);
  gst_plugin_feature_list_free (list);
  gst_object_unref (bus);
  gst_element_set_state (pipeline, GST_STATE_NULL);
  gst_object_unref (pipeline);
  return 0;
}

int
main (int argc, char *argv[])
{
#if defined(__APPLE__) && TARGET_OS_MAC && !TARGET_OS_IPHONE
  return gst_macos_main ((GstMainFunc) tutorial_main, argc, argv, NULL);
#else
  return tutorial_main (argc, argv);
#endif
}
```

## 攻略

首先，我们playbin通过设置标志来表明我们需要音频可视化GST_PLAY_FLAG_VIS。如果媒体文件已经包含视频，则此标志无效。

```c
/* Set the visualization flag */
g_object_get (pipeline, "flags", &flags, NULL);
flags |= GST_PLAY_FLAG_VIS;
g_object_set (pipeline, "flags", flags, NULL);
```

如果用户未强制指定可视化插件，playbin则将使用默认设置 goom（如果音频可视化不可用，则音频可视化将被禁用goom）。本教程的其余部分将介绍如何查找可用的可视化元素并强制指定一个playbin。

```c
/* Get a list of all visualization plugins */
list = gst_registry_feature_filter (gst_registry_get (), filter_vis_features, FALSE, NULL);
```

gst_registry_feature_filter()检查 GStreamer 注册表中当前的所有元素，并选择函数返回 TRUE 的元素filter_vis_features。此函数仅选择可视化插件：

```c
/* Return TRUE if this is a Visualization element */
static gboolean filter_vis_features (GstPluginFeature *feature, gpointer data) {
  GstElementFactory *factory;

  if (!GST_IS_ELEMENT_FACTORY (feature))
    return FALSE;
  factory = GST_ELEMENT_FACTORY (feature);
  if (!g_strrstr (gst_element_factory_get_klass (factory), "Visualization"))
    return FALSE;

  return TRUE;
}
```

关于 GStreamer 元素的组织结构，这里有一些理论基础：GStreamer 在运行时加载的每个文件都称为一个插件（Plugin GstPlugin）。一个插件可以包含多个特性（Feature ）。特性有多种类型，其中包括我们一直用来构建元素（Element）的GstPluginFeature元素工厂（Element Factory）。GstElementFactoryGstElement

此函数会忽略所有非工厂类型的特性，以及所有类（通过 `Factory.class` 获取 gst_element_factory_get_klass()）不包含“Visualization”的工厂。正如 `Factory.class` 的文档所述GstElementFactory，工厂的类是一个“描述元素类型的字符串，以斜杠 (/) 分隔的无序列表形式”。类的示例包括“Source/Network”、“Codec/Decoder/Video”、“Codec/Encoder/Audio”或“Visualization”。

```c
/* Print their names */
g_print("Available visualization plugins:\n");
for (walk = list; walk != NULL; walk = g_list_next (walk)) {
  const gchar *name;
  GstElementFactory *factory;

  factory = GST_ELEMENT_FACTORY (walk->data);
  name = gst_element_factory_get_longname (factory);
  g_print("  %s\n", name);

  if (selected_factory == NULL || g_str_has_prefix (name, "GOOM")) {
    selected_factory = factory;
  }
}
```

一旦我们有了可视化插件列表，我们就打印它们的名称（gst_element_factory_get_longname()），然后选择一个（在本例中为 GOOM）。

```c
/* We have now selected a factory for the visualization element */
g_print ("Selected '%s'\n", gst_element_factory_get_longname (selected_factory));
vis_plugin = gst_element_factory_create (selected_factory, NULL);
if (!vis_plugin)
  return -1;
```

选定的工厂用于实例化一个实际GstElement对象，然后playbin通过vis-plugin属性将其传递给：

```c
/* set vis plugin for playbin */
g_object_set (pipeline, "vis-plugin", vis_plugin, NULL);
```

我们完成了。
