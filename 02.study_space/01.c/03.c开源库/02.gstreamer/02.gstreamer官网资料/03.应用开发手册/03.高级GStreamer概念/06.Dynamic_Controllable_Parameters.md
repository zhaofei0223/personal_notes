# 动态可控参数

## 入门

GStreamer 属性通常使用 `setProperties()` 方法设置g_object_set()，但要可靠地控制这些调用的时机，使更改影响到特定的流时间段，几乎是不可能的。控制器子系统提供了一种轻量级的方法，可以 GObject在流时间段内调整属性。

控制器会考虑时间因素；它的工作原理是 GstControlSource使用控制绑定将控制源附加到属性上。控制源为给定的时间戳提供值，这些值通常在 0.0 到 1.0 的范围内。控制绑定将控制值映射到GObject它们所绑定的属性，并转换类型和缩放比例以适应目标属性的值范围。在运行时，元素会持续获取当前流时间的值变化以更新GObject属性。GStreamer 已经包含了一些不同的GstControlSource控制源和控制绑定，但应用程序可以通过继承相应的基类来定义自己的控制源和控制绑定。

控制器机制的大部分都已在 . 中实现GstObject。控制器和控制绑定的基类GstControlSource也包含在核心库中，但现有的实现包含在库中gstcontroller，因此您需要根据需要将这些头文件包含在应用程序的源文件中：

```c
#include <gst/gst.h>
#include <gst/controller/gstinterpolationcontrolsource.h>
#include <gst/controller/gstdirectcontrolbinding.h>
...
```

除了包含正确的头文件之外，您的应用程序还应该链接到 gstreamer-controller共享库。要获取所需的编译器和链接器标志，您可以使用：

```shell
pkg-config --libs --cflags gstreamer-controller-1.0
```

## 设置参数控制

如果我们已经搭建好了管道，并且想要控制一些参数，首先需要创建一个GstControlSource。让我们使用插值 GstControlSource：

```c
csource = gst_interpolation_control_source_new ();
g_object_set (csource, "mode", GST_INTERPOLATION_MODE_LINEAR, NULL);
```

现在，我们需要将控件绑定GstControlSource到 gobject 属性上。这可以通过控件绑定来实现。一个控件源可以使用不同的控件绑定绑定到多个对象属性（甚至可以绑定到不同对象）。

```c
gst_object_add_control_binding (object, gst_direct_control_binding_new (object, "prop1", csource));
```

这种类型GstControlSource从带有时间戳的参数更改列表中获取新的属性值。例如，数据源可以通过平滑参数更改来填充数据空白。可以通过设置 `mode` 属性来配置此行为GstControlSource。其他控制源（例如，通过调用函数生成值流）sin()具有用于控制频率等的参数。由于GstControlSource`s` 也是 GstObject`s`，因此也可以将GstControlSource`s` 附加到这些属性。

现在我们可以设置一些控制点。这些控制点是带有时间戳的 gdouble 值，通常在 0.0 到 1.0 的范围内。值 1.0 稍后会映射到目标属性值范围内的最大值。当到达指定的时间戳时，这些值就会生效，但它们仍然保留在列表中。例如，如果管道运行一个循环（使用分段查找），则控制曲线也会重复执行。

```c
GstTimedValueControlSource *tv_csource = (GstTimedValueControlSource *)csource;
gst_timed_value_control_source_set (tv_csource, 0 * GST_SECOND, 0.0);
gst_timed_value_control_source_set (tv_csource, 1 * GST_SECOND, 1.0);
```

现在一切就绪。如果我们将其绑定GstControlSource到音量属性，就会听到 1 秒的淡入效果。但要注意：GStreamer 的默认音量元素有一个volume范围从 0.0 到 10.0 的属性。如果GstControlSource将上述代码绑定到此属性，音量将飙升至 400%！

最后一点：控制器子系统内置了实时模式。即使属性已被GstControlSource赋值，也可以通过设置属性值来改变其 GObject值g_object_set()。这在将属性绑定到 GUI 控件时非常有用GObject。当用户使用控件调整值时，可以设置属性GObject值，并且该值会一直保持有效，直到下一个被编程的GstControlSource值覆盖为止。这同样适用于平滑参数，但不适用于GstControlSource会不断更新属性的控件，例如 `tf.get_properties` GstLFOControlSource。
