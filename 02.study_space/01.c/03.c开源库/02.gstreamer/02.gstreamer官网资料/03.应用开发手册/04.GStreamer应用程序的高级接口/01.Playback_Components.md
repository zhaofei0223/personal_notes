# 播放组件

GStreamer 包含多个高级组件，旨在简化应用程序开发人员的工作。本文（目前）讨论的所有组件都面向媒体播放。这些组件的设计理念是尽可能与 GStreamer 管道紧密集成，同时隐藏媒体类型检测的复杂性以及“高级 GStreamer 概念”中讨论的其他一些较为复杂的主题。

我们目前建议用户根据自身需求使用 playbin（参见 Playbin）或 decodebin（参见Decodebin）。Playbin 是所有简单媒体播放相关功能的推荐解决方案，它应该能够即插即用。Decodebin 是一款更灵活的自动插件，可用于添加更多高级功能，例如播放列表支持、音频轨道淡入淡出等等。不过，它的编程接口比 playbin 更底层。

## 播放游戏

Playbin 是一个可以使用标准 GStreamer API 创建的元素（例如 `GStreamer.getPlaybin( gst_element_factory_make ())`）。该工厂的名称也恰好是“playbin”。由于 Playbin 是一个`GStreamer.getPlaybin()` 类型的元素GstPipeline（因此也是一个 ` GstElementGStreamer.getPlaybin()` 类型的元素），它自动支持该类的所有特性，包括错误处理、标签支持、状态管理、获取流位置、查找等等。

设置 playbin 管道非常简单，只需创建一个 playbin 元素实例，使用 playbin 的“uri”属性设置文件位置，然后将该元素的状态设置为 true GST_STATE_PLAYING（位置必须是有效的 URI，例如“<协议>://<位置>”，例如 file:///tmp/my.ogg 或 http://www.example.org/stream.ogg）。playbin 内部会设置一个管道来播放媒体文件。

```c
#include <gst/gst.h>

[.. my_bus_callback goes here ..]

gint
main (gint   argc,
      gchar *argv[])
{
  GMainLoop *loop;
  GstElement *play;
  GstBus *bus;

  /* init GStreamer */
  gst_init (&argc, &argv);
  loop = g_main_loop_new (NULL, FALSE);

  /* make sure we have a URI */
  if (argc != 2) {
    g_print ("Usage: %s <URI>\n", argv[0]);
    return -1;
  }

  /* set up */
  play = gst_element_factory_make ("playbin", "play");
  g_object_set (G_OBJECT (play), "uri", argv[1], NULL);

  bus = gst_pipeline_get_bus (GST_PIPELINE (play));
  gst_bus_add_watch (bus, my_bus_callback, loop);
  gst_object_unref (bus);

  gst_element_set_state (play, GST_STATE_PLAYING);

  /* now run */
  g_main_loop_run (loop);

  /* also clean up */
  gst_element_set_state (play, GST_STATE_NULL);
  gst_object_unref (GST_OBJECT (play));

  return 0;
}
```

Playbin 具有一些之前已经讨论过的功能：

- 可设置视频和音频输出（使用“video-sink”和“audio-sink”属性）。
- 大部分功能可控且可追踪GstElement，包括错误处理、EOS 处理、标签处理、状态处理（通过 GstBus）、媒体位置处理和搜索。
- 缓冲网络源，缓冲区满通知通过该缓冲区传递GstBus。
- 支持纯音频媒体的可视化。
- 支持字幕，包括媒体文件内的字幕和单独文件中的字幕。对于单独字幕文件，请使用“suburi”属性。
- 支持流选择和禁用。如果您的媒体包含多个音频或字幕轨道，您可以动态选择要播放的轨道，或者完全关闭其中一个（这对于关闭字幕尤其有用）。要进行这些操作，请使用“current-text”和其他相关属性。

为了方便起见，可以使用命令“gst-launch-1.0 playbin uri=file:///path/to/file”在命令行上测试“playbin”。

## 解码箱

Decodebin 是 playbin 的实际自动插拔后端，我们在上一节中已经讨论过。简而言之，Decodebin 会接收来自与其 sinkpad 连接的源的输入，并尝试检测流中包含的媒体类型，并为每种类型设置解码器例程。它会自动选择解码器。对于每个解码后的流，它会发出“pad-added”信号，以告知客户端新发现的解码流。对于未知流（可能是整个流），它会发出“unknown-type”信号。然后，应用程序负责将错误报告给用户。

```c
#include <gst/gst.h>


[.. my_bus_callback goes here ..]



GstElement *pipeline, *audio;

static void
cb_newpad (GstElement *decodebin,
       GstPad     *pad,
       gpointer    data)
{
  GstCaps *caps;
  GstStructure *str;
  GstPad *audiopad;

  /* only link once */
  audiopad = gst_element_get_static_pad (audio, "sink");
  if (GST_PAD_IS_LINKED (audiopad)) {
    g_object_unref (audiopad);
    return;
  }

  /* check media type */
  caps = gst_pad_query_caps (pad, NULL);
  str = gst_caps_get_structure (caps, 0);
  if (!g_strrstr (gst_structure_get_name (str), "audio")) {
    gst_caps_unref (caps);
    gst_object_unref (audiopad);
    return;
  }
  gst_caps_unref (caps);

  /* link'n'play */
  gst_pad_link (pad, audiopad);

  g_object_unref (audiopad);
}

gint
main (gint   argc,
      gchar *argv[])
{
  GMainLoop *loop;
  GstElement *src, *dec, *conv, *sink;
  GstPad *audiopad;
  GstBus *bus;

  /* init GStreamer */
  gst_init (&argc, &argv);
  loop = g_main_loop_new (NULL, FALSE);

  /* make sure we have input */
  if (argc != 2) {
    g_print ("Usage: %s <filename>\n", argv[0]);
    return -1;
  }

  /* setup */
  pipeline = gst_pipeline_new ("pipeline");

  bus = gst_pipeline_get_bus (GST_PIPELINE (pipeline));
  gst_bus_add_watch (bus, my_bus_callback, loop);
  gst_object_unref (bus);

  src = gst_element_factory_make ("filesrc", "source");
  g_object_set (G_OBJECT (src), "location", argv[1], NULL);
  dec = gst_element_factory_make ("decodebin", "decoder");
  g_signal_connect (dec, "pad-added", G_CALLBACK (cb_newpad), NULL);
  gst_bin_add_many (GST_BIN (pipeline), src, dec, NULL);
  gst_element_link (src, dec);

  /* create audio output */
  audio = gst_bin_new ("audiobin");
  conv = gst_element_factory_make ("audioconvert", "aconv");
  audiopad = gst_element_get_static_pad (conv, "sink");
  sink = gst_element_factory_make ("alsasink", "sink");
  gst_bin_add_many (GST_BIN (audio), conv, sink, NULL);
  gst_element_link (conv, sink);
  gst_element_add_pad (audio,
      gst_ghost_pad_new ("sink", audiopad));
  gst_object_unref (audiopad);
  gst_bin_add (GST_BIN (pipeline), audio);

  /* run */
  gst_element_set_state (pipeline, GST_STATE_PLAYING);
  g_main_loop_run (loop);

  /* cleanup */
  gst_element_set_state (pipeline, GST_STATE_NULL);
  gst_object_unref (GST_OBJECT (pipeline));

  return 0;
}

```

Decodebin 与 playbin 类似，支持以下功能：

- 可以将无限数量的包含流解码到解码后的输出垫。
- GstElement在所有方面都作为处理，包括标签或错误转发和状态处理。

虽然 decodebin 是一个不错的自动插拔工具，但它有很多功能无法实现，而且它本来就不是用来实现这些功能的：

- 处理已知媒体类型（例如 DVD、音频 CD 等）的输入流。
- 选择流（例如，在多语言媒体流的情况下播放哪个音轨）。
- 在解码后的视频流上叠加字幕。

可以通过命令行轻松测试 Decodebin，例如使用命令gst-launch-1.0 filesrc location=file.ogg ! decodebin ! audioconvert ! audioresample ! autoaudiosink。

## URI解码

uridecodebin 元素与 decodebin 非常相似，只是它会根据给定的 URI 协议自动插入源插件。

当 URI 来自网络速度较慢的源时，Uridecodebin 还会自动插入缓冲元素。缓冲元素会发布 BUFFERING 消息，应用程序需要按照 “缓冲”部分中的说明进行处理。可以使用以下属性来配置缓冲方法：

- buffer-size 属性允许您配置 buffer 元素的最大大小（以字节为单位）。
- buffer-duration 属性允许您配置缓冲区元素的最大持续时间。该时间将根据网络比特率进行估算。
- 通过下载属性，您可以启用下载缓冲方法，具体说明请参见“下载缓冲”部分。将此选项设置为 TRUE 将仅对选定的格式（例如 QuickTime、Flash 视频、AVI 和 WebM）启用下载缓冲。
- 您还可以使用 use-buffering 属性为已解析/解复用的数据启用缓冲。这对于在速度较慢的随机访问介质（例如网络文件服务器）上启用缓冲非常有用。

URIDecodebin 可以通过命令行轻松测试，例如使用命令gst-launch-1.0 uridecodebin uri=file:///file.ogg ! ! audioconvert ! audioresample ! autoaudiosink。

## 游戏池

playsink 元素是一个功能强大的接收器元素。它具有用于接收原始解码音频、视频和文本的请求接口，并会自动配置以播放媒体流。它具有以下特性：

- 它公开了 GstStreamVolume、GstVideoOverlay、GstNavigation 和 GstColorBalance 接口，并在需要时自动插入软件元素来实现这些接口。
- 它会自动连接转换元件。
- 当没有视频输入时，可以选择渲染可视化效果。
- 可配置的接收器元件。
- 可配置音频/视频同步偏移，以微调混流不良文件中的同步。
- 支持对最后一帧视频进行快照。

以下示例展示了如何使用 playsink。我们使用 uridecodebin 元素将音频和视频流解码成原始流，然后将其链接到 playsink 请求 pad。这里我们只链接了第一个音频和视频 pad，您可以使用输入选择器来链接所有 pad。

```c
#include <gst/gst.h>


[.. my_bus_callback goes here ..]





GstElement *pipeline, *sink;

static void
cb_pad_added (GstElement *dec,
          GstPad     *pad,
          gpointer    data)
{
  GstCaps *caps;
  GstStructure *str;
  const gchar *name;
  GstPadTemplate *templ;
  GstElementClass *klass;

  /* check media type */
  caps = gst_pad_query_caps (pad, NULL);
  str = gst_caps_get_structure (caps, 0);
  name = gst_structure_get_name (str);

  klass = GST_ELEMENT_GET_CLASS (sink);

  if (g_str_has_prefix (name, "audio")) {
    templ = gst_element_class_get_pad_template (klass, "audio_sink");
  } else if (g_str_has_prefix (name, "video")) {
    templ = gst_element_class_get_pad_template (klass, "video_sink");
  } else if (g_str_has_prefix (name, "text")) {
    templ = gst_element_class_get_pad_template (klass, "text_sink");
  } else {
    templ = NULL;
  }

  if (templ) {
    GstPad *sinkpad;

    sinkpad = gst_element_request_pad (sink, templ, NULL, NULL);

    if (!gst_pad_is_linked (sinkpad))
      gst_pad_link (pad, sinkpad);

    gst_object_unref (sinkpad);
  }

  gst_clear_caps (&caps);
}

gint
main (gint   argc,
      gchar *argv[])
{
  GMainLoop *loop;
  GstElement *dec;
  GstBus *bus;

  /* init GStreamer */
  gst_init (&argc, &argv);
  loop = g_main_loop_new (NULL, FALSE);

  /* make sure we have input */
  if (argc != 2) {
    g_print ("Usage: %s <uri>\n", argv[0]);
    return -1;
  }

  /* setup */
  pipeline = gst_pipeline_new ("pipeline");

  bus = gst_pipeline_get_bus (GST_PIPELINE (pipeline));
  gst_bus_add_watch (bus, my_bus_callback, loop);
  gst_object_unref (bus);

  dec = gst_element_factory_make ("uridecodebin", "source");
  g_object_set (G_OBJECT (dec), "uri", argv[1], NULL);
  g_signal_connect (dec, "pad-added", G_CALLBACK (cb_pad_added), NULL);

  /* create audio output */
  sink = gst_element_factory_make ("playsink", "sink");
  gst_util_set_object_arg (G_OBJECT (sink), "flags",
      "soft-colorbalance+soft-volume+vis+text+audio+video");
  gst_bin_add_many (GST_BIN (pipeline), dec, sink, NULL);

  /* run */
  gst_element_set_state (pipeline, GST_STATE_PLAYING);
  g_main_loop_run (loop);

  /* cleanup */
  gst_element_set_state (pipeline, GST_STATE_NULL);
  gst_object_unref (GST_OBJECT (pipeline));

  return 0;
}
```

此示例会根据您提供的内容显示音频和视频。尝试使用音频文件运行此示例，您会发现它会显示可视化效果。您可以通过更改 `vis-plugin` 属性在运行时更改可视化效果。
