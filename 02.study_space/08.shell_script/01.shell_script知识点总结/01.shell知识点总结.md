## 001、启动SSH代理

```shell
echo "Sync public key!"
eval "$(ssh-agent -s)"
ssh-add
```

这段命令的作用是启动SSH代理（ssh-agent）并尝试将本地的SSH私钥添加到代理中，以便后续通过SSH连接远程服务器时无需重复输入密码。

具体分解如下：

1.  `echo "Sync public key!"`:
    这只是一个打印信息的命令，用于在终端中显示提示信息“Sync public key!”，提醒用户当前正在执行密钥同步操作。它本身不执行任何功能。

2.  `eval "$(ssh-agent -s)"`:
    这是核心步骤，用于启动SSH代理进程。
    *   `ssh-agent -s`：启动一个SSH代理进程。`-s` 参数表示输出格式为Shell脚本格式（适用于bash、zsh等）。
    *   `eval`：执行`ssh-agent -s`命令的输出结果。`ssh-agent`的输出包含两个关键的环境变量（`SSH_AUTH_SOCK`和`SSH_AGENT_PID`），`eval`会将这些变量设置到当前的Shell会话中。只有设置了这些环境变量，后续的`ssh-add`命令才能与这个正在运行的代理进程通信。
    *   简单来说，这行命令启动了SSH代理，并让当前终端能与之交互。

3.  `ssh-add`:
    这个命令用于将SSH私钥添加到刚刚启动的代理中。
    *   `ssh-add` 命令默认会尝试添加 `~/.ssh/` 目录下的标准私钥文件，如 `id_rsa`、`id_ecdsa`、`id_ed25519` 等。
    *   如果私钥文件有密码（passphrase），执行此命令时会提示你输入一次密码。输入正确后，私钥就会被加载到内存中，由`ssh-agent`管理。
    *   注意：你提供的命令中 `ssh-add` 后面跟着 `shell`，这很可能是一个笔误或不完整的命令。正确的用法应该是 `ssh-add`（不加参数）或 `ssh-add ~/.ssh/your_private_key`（指定私钥文件路径）。如果直接运行 `ssh-add shell`，系统会尝试查找一个名为 `shell` 的私钥文件，这通常不存在，会导致命令失败。

总结来说，这段命令的意图是：
1.  提示用户正在同步公钥。
2.  启动一个SSH代理进程。
3.  将本地的SSH私钥（默认文件）加载到代理中。

完成这些步骤后，你就可以使用 `ssh`、`scp` 等命令连接远程服务器了，只要服务器上存有对应公钥，整个过程就无需再输入密码了。 但请修正 `ssh-add` 后面的 `shell` 为正确的私钥文件名或删除它以使用默认文件。

## 002、$后各参数总结

在Shell脚本中，`$`符号后面通常跟随不同的字符和结构，用以引用变量、特殊参数、位置参数（positional parameters）、数组元素等。下面是一些常见的用法及其解释：

1. 普通变量

```bash
variable="value"
echo $variable
```

2. 位置参数（Positional Parameters）

位置参数是传递给脚本的参数。

- `$0`：脚本名称
- `$1`：第一个参数
- `$2`：第二个参数
- 以此类推...

例如：

```bash
echo $1  输出第一个参数的值
```

3. 特殊参数

- `$`：传递给脚本的参数个数
- `$*`：所有传递给脚本的参数，作为一个单一的字符串
- `$@`：所有传递给脚本的参数，每个都作为独立的字符串
- `$$`：脚本运行的当前进程ID
- `$?`：上一个命令的退出状态
- `$-`：当前shell启动时的选项，如`set`命令的选项集合

4. 字符串操作

- `${var}`：变量`var`的长度
- `${var:pos}`：从位置`pos`开始提取子字符串
- `${var:pos:len}`：从位置`pos`开始，长度为`len`的子字符串
- `${varpattern}`：删除变量值中最小匹配的前缀模式`pattern`
- `${varpattern}`：删除变量值中最大匹配的前缀模式`pattern`
- `${var%pattern}`：删除变量值中小匹配的后缀模式`pattern`
- `${var%%pattern}`：删除变量值中最大匹配的后缀模式`pattern`
- `${var/pattern/replacement}`：将第一个匹配的`pattern`替换为`replacement`
- `${var//pattern/replacement}`：将所有匹配的`pattern`替换为`replacement`

5. 数组操作

- `array[index]`：访问数组元素
- `${array[@]}`：访问数组中的所有元素
- `${array[@]}`：数组元素的数量
- `${array[@]:start:length}`：从索引`start`开始，长度为`length`的子数组

6. 间接引用（Indirect Reference）

使用`!`符号进行间接引用。例如，如果你有一个变量名存储在另一个变量中，你可以使用这种方式来引用它。

```bash
name="value"
varname="name"
echo ${!varname}  输出 value
```

7. 算术扩展（Arithmetic Expansion）

```bash
echo $((2 + 2))  输出 4
```
或者使用双括号进行更复杂的算术运算。
```bash
((a = 5 + 3))
echo $a  输出 8
```

8. 命令替换（Command Substitution）

使用反引号`` `command` ``或`$(command)`来执行命令并使用其输出。
```bash
today=$(date)
echo $today  输出当前日期和时间
```

通过以上这些方式，你可以灵活地在Shell脚本中引用和操作变量与参数。

## 003、计算任务耗时的shell脚本模板

```shell
#!/bin/bash

# 1. 记录开始时间（纳秒级）
start_time=$(date +%s%N)

# --------------------------
# 在此放置要执行的任务/命令
echo "任务开始..."
sleep 2  # 模拟耗时任务
echo "任务结束."
# --------------------------

# 2. 记录结束时间（纳秒级）
end_time=$(date +%s%N)

# 3. 计算耗时（纳秒转秒，保留3位小数）
# 使用 awk 进行高精度浮点数计算
duration=$(echo "($end_time - $start_time) / 1000000000" | bc -l)
printf "任务总耗时: %.3f 秒\n" "$duration"

# (可选) 转换成时:分:秒格式
duration_s=$(echo "($end_time - $start_time) / 1000000000" | bc)
printf "耗时: %02d:%02d:%02d\n" $(($duration_s/3600)) $(($duration_s%3600/60)) $(($duration_s%60))
```

## 005、shell脚本中${}与$()的区别

在Shell脚本中，`${}` 和 `$()` 是两种功能完全不同的语法结构，分别用于变量替换和命令替换。

`${}`：变量替换与字符串操作

`${}` 主要用于引用和操作Shell变量，它能精确界定变量名的边界，并提供一系列强大的字符串处理功能。

*   基本变量引用：在大多数情况下，`$var` 和 `${var}` 效果相同，但使用 `${}` 更清晰、更安全，尤其是在变量名后紧跟其他字符时。
    ```bash
    name="Alice"
    echo "Hello, ${name}"  输出: Hello, Alice
    echo "Hello, $name"    输出: Hello, Alice (效果相同)
    
    file="test.txt"
    echo "${file}.bak"     推荐：输出: test.txt.bak
    echo "$file.bak"       可能出错：Shell会尝试查找名为file.bak的变量
    ```

*   高级字符串操作：`${}` 支持多种字符串截取、替换和长度计算。
    *   截取子串：`${var:start:length}` 从指定位置提取字符。
        ```bash
        str="HelloWorld"
        echo "${str:0:5}"    输出: Hello (从第0个字符开始，取5个)
        echo "${str: -5}"    输出: World (从倒数第5个字符开始取到末尾)
        ```
    *   模式匹配截断：使用 ``、``、`%`、`%%` 删除字符串的前缀或后缀。
        ```bash
        path="/home/user/file.txt"
        echo "${path*/}"   输出: file.txt (删除最后一个/及其左边的所有内容)
        echo "${path%.*}"    输出: /home/user/file (删除最后一个.及其右边的所有内容)
        ```
    *   字符串替换：`${var/pattern/replacement}` 替换第一个匹配项，`${var//pattern/replacement}` 替换所有匹配项。
        ```bash
        text="apple apple banana"
        echo "${text/apple/orange}"   输出: orange apple banana
        echo "${text//apple/orange}"  输出: orange orange banana
        ```
    *   获取长度：`${var}` 返回变量值的字符数。
        ```bash
        msg="Hello"
        echo "${msg}"  输出: 5
        ```
    *   默认值与赋值：`${var:-default}`、`${var:=default}` 等语法可在变量未设置或为空时提供默认值。
        ```bash
        echo "${username:-Guest}"  如果username未设置，输出Guest
        ```

`$()`：命令替换

`$()` 用于执行一个命令，并将其标准输出结果替换到命令行中。它等价于旧式的反引号 `` `command` ``，但更推荐使用，因为其语法更清晰，支持嵌套。

*   执行命令并获取输出：将命令的输出赋值给变量或作为参数传递。
    ```bash
    current_date=$(date)
    echo "今天日期: $current_date"
    
    file_count=$(ls | wc -l)
    echo "当前目录有 $file_count 个文件"
    ```

*   嵌套使用：`$()` 可以轻松地嵌套使用，而反引号则需要复杂的转义。
    ```bash
    推荐：清晰易读
    content=$(cat $(find . -name "*.txt" | head -1))
    
    不推荐：需要转义，易出错
    content=`cat \`find . -name "*.txt" | head -1\``
    ```

总结对比

| 特性 | `${}` | `$()` |
| :--- | :--- | :--- |
| 核心用途 | 变量替换 和 字符串操作 | 命令替换 (执行命令并获取输出) |
| 操作对象 | 变量的值、字符串 | 命令的输出 |
| 主要功能 | 引用变量、截取子串、模式匹配、替换、计算长度、设置默认值 | 执行外部命令，获取其标准输出 |
| 示例 | `${file*/}`, `${var:-default}`, `${var}` | `$(date)`, `$(ls -l)`, `$(echo "Hello")` |
| 推荐理由 | 精确界定变量边界，避免歧义，功能强大 | 语法清晰，支持嵌套，是现代Shell的首选 |

## 006、shell脚本中的unset的作用

在Shell脚本中，`unset` 是一个内置命令，主要用于删除变量或函数，以清理当前Shell环境，避免变量污染或资源浪费。

主要作用

- 删除变量：移除通过 `VAR=value` 定义的普通变量或环境变量（使用 `export` 导出的变量），使其在当前Shell中不再可用。
- 删除函数：移除通过 `function name() { ... }` 或 `name() { ... }` 定义的Shell函数，使其无法再被调用。
- 管理临时变量：在脚本执行过程中创建临时变量，任务完成后使用 `unset` 清理，保持环境整洁，提高脚本可维护性。
- 避免变量冲突：在脚本开始时清理可能影响执行的旧变量，确保运行环境纯净。

基本语法

```bash
unset [-fv] 名称 [名称...]
```

- `-f`：仅删除函数。
- `-v`：仅删除变量（默认行为，可省略）。
- 多个名称：可用空格分隔，一次性删除多个变量或函数。

使用示例

1. 删除变量
   ```bash
   MY_VAR="Hello, World!"
   echo $MY_VAR  输出: Hello, World!
   unset MY_VAR
   echo $MY_VAR  无输出（变量已被删除）
   ```

2. 删除函数
   ```bash
   greet() {
       echo "Hello!"
   }
   greet  输出: Hello!
   unset -f greet
   greet  报错: bash: greet: command not found
   ```

3. 同时删除多个变量
   ```bash
   VAR1="value1"
   VAR2="value2"
   VAR3="value3"
   unset VAR1 VAR2 VAR3  一次性删除三个变量
   ```

4. 删除数组元素
   ```bash
   my_array=(1 2 3)
   unset my_array  删除索引为1的元素
   echo ${my_array[@]}  输出: 1 3
   ```

重要注意事项

- 只读变量无法删除：若变量使用 `readonly` 声明为只读，`unset` 会失败并报错。
  ```bash
  readonly MY_RO="cannot be deleted"
  unset MY_RO  报错: cannot unset: readonly variable
  ```
- 仅影响当前Shell：`unset` 只在当前Shell进程中生效，不会影响子Shell或其它终端会话。
- 变量不存在不报错：尝试删除一个不存在的变量或函数，`unset` 会静默忽略，不会报错。
- 不能删除系统关键变量：如 `HOME`、`PATH` 等，虽然可以删除，但可能导致Shell行为异常，不建议随意操作。

总结

在Shell脚本中，`unset` 是一种高效、安全的环境管理工具，常用于：
- 清理临时变量
- 防止变量名冲突
- 释放内存资源
- 保证脚本执行环境的纯净性

合理使用 `unset` 能显著提升脚本的健壮性和可维护性。

## 007、shell脚本的括号与方括号的区别

在Shell脚本中，括号（`()`、`(( ))`）和方括号（`[]`、`[[ ]]`）是功能完全不同的语法结构，它们分别用于命令执行/算术运算和条件测试。以下是它们的核心区别：

1. 小括号 `()` 与 双小括号 `(( ))`

- `()`（单小括号）：用于命令组或命令替换。
  - 命令组：括号内的命令会在一个子Shell中执行，不会影响当前Shell的变量环境。
    ```bash
    (a=10; echo "Inside: $a")  输出: Inside: 10
    echo "Outside: $a"         输出: Outside: （原变量a未被修改）
    ```
  - 命令替换：获取命令的输出结果。
    ```bash
    current_date=$(date)  将date命令的输出赋值给变量
    ```

- `(( ))`（双小括号）：用于算术运算和整数比较。
  - 支持C语言风格的算术表达式，如 `+`, `-`, `*`, `/`, `++`, `--`, `**`（幂）等。
  - 变量名不需要加 `$` 前缀。
  - 表达式结果为0时返回退出码1（假），非0时返回0（真）。
    ```bash
    a=5
    ((a++))                    a 变为 6
    if (( a > 3 )); then       直接比较，无需 -gt
        echo "a is greater than 3"
    fi
    echo $(( 16FF ))          输出: 255（十六进制转十进制）
    ```

2. 单方括号 `[]` 与 双方括号 `[[]]`

- `[]`（单方括号）：是 `test` 命令的别名，用于基本条件测试，遵循POSIX标准，兼容性好。
  - 字符串比较：使用 `=` 或 `!=`。
  - 整数比较：必须使用专用操作符，如 `-eq`, `-ne`, `-lt`, `-gt`, `-le`, `-ge`。不能使用 `<`, `>`。
  - 逻辑运算：使用 `-a`（与）、`-o`（或）。
  - 必须加空格，变量建议用引号包裹以防空值错误。
    ```bash
    if [ "$num" -eq 10 ]; then
        echo "num equals 10"
    fi
    if [ "$str" = "hello" ]; then
        echo "string is hello"
    fi
    ```

- `[[ ]]`（双方括号）：是Bash的扩展关键字，功能更强大、更安全。
  - 支持 `==`, `!=`, `<`, `>`, `<=`, `>=` 等直接比较运算符（无需 `-eq` 等）。
  - 支持模式匹配（通配符）和正则表达式（使用 `=~`）。
  - 不需要对变量加引号（但加了更安全）。
  - 支持 `&&`、`||` 等逻辑运算符，语法更直观。
    ```bash
    if [[ $num -eq 10 ]]; then           仍支持 -eq
        echo "num equals 10"
    fi
    if [[ $str  "hello" ]]; then       可用 ，无需引号
        echo "string is hello"
    fi
    if [[ $file == *.txt ]]; then        模式匹配：检查是否以 .txt 结尾
        echo "It's a text file"
    fi
    if [[ $text =~ ^[0-9]+$ ]]; then     正则匹配：检查是否为纯数字
        echo "It's a number"
    fi
    if [[ $a -gt 5 && $b -lt 10 ]]; then 可直接用 &&, ||
        echo "Condition met"
    fi
    ```

总结对比表

| 类型 | 名称 | 主要用途 | 关键特性 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| `()` | 小括号 | 命令组、命令替换 | 在子Shell中执行，不影响父Shell | `(cd /tmp; pwd)` |
| `(( ))` | 双小括号 | 算术运算、整数比较 | 支持C语言语法，变量无需 `$` | `(( x = 5 + 3 ))` |
| `[]` | 单方括号 | 基本条件测试 | POSIX标准，需用 `-eq` 等操作符 | `[ "$a" -eq 1 ]` |
| `[[ ]]` | 双方括号 | 增强条件测试 | 支持 `==`, `<`, `=~` 正则，更安全灵活 | `[[ $a > 1 && $b =~ ^[a-z]+$ ]]` |

推荐实践：在Bash脚本中，优先使用 `[[ ]]` 进行条件判断，使用 `(( ))` 进行算术运算，它们更强大、更不易出错。`[]` 和 `()` 保留用于需要最大兼容性的场景。

## 008、shell脚本的返回值和函数返回值区别

Shell脚本的返回值和函数返回值在概念上是相关的，但它们的具体含义和使用场景有所不同。

简单来说：
*   函数返回值：特指函数执行完毕后，向调用者传递的信息，主要分为退出状态码和输出结果两种。
*   Shell脚本返回值：通常指整个脚本执行完毕后的退出状态码，它决定了脚本的执行结果（成功或失败）。

以下是详细的对比：

函数返回值

函数返回值主要有两种方式，它们服务于不同的目的：

1.  退出状态码 (Exit Status Code) - 使用 `return`
    *   用途：主要用于指示函数执行的成功或失败状态，常用于流程控制（如 `if` 语句）。
    *   限制：只能返回一个 0 到 255 之间的整数。约定俗成，`0` 表示成功，非 `0` 表示失败。
    *   获取方式：在函数调用后，通过特殊变量 `$?` 来获取。
    *   示例：
        ```bash
        function check_file() {
            if [ -f "$1" ]; then
                return 0  文件存在，返回成功
            else
                return 1  文件不存在，返回失败
            fi
        }

        check_file "example.txt"
        if [ $? -eq 0 ]; then
            echo "文件存在"
        else
            echo "文件不存在"
        fi
        ```

2.  输出结果 (Output) - 使用 `echo`
    *   用途：用于返回函数计算出的任意数据，如字符串、数字、文件内容等。
    *   限制：没有数据类型的限制，可以返回任何字符串或数值。
    *   获取方式：通过命令替换 `$(function_name)` 或 `` `function_name` `` 来捕获函数的输出。
    *   示例：
        ```bash
        function get_sum() {
            local a=$1
            local b=$2
            echo $((a + b))  将计算结果输出到标准输出
        }

        result=$(get_sum 5 3)
        echo "5 和 3 的和是: $result"  输出: 5 和 3 的和是: 8
        ```

Shell脚本返回值

Shell脚本的返回值，通常指的是脚本执行完毕后，其退出状态码。

*   来源：这个退出状态码默认是脚本中最后一条执行的命令的退出状态码。
*   设置方式：可以使用 `exit [n]` 命令显式地指定脚本的退出状态码。`n` 的范围同样是 0-255。
*   用途：用于告诉调用该脚本的父进程（如另一个脚本、shell或系统）该脚本是否成功执行。`0` 表示成功，非 `0` 表示失败。
*   获取方式：在调用脚本后，通过 `$?` 获取。
*   示例：
    ```bash
    !/bin/bash
    my_script.sh
    echo "正在执行脚本..."
    if [ -f "required_file.txt" ]; then
        echo "找到必需文件，脚本成功。"
        exit 0  显式设置脚本成功退出
    else
        echo "错误：未找到必需文件。"
        exit 1  显式设置脚本失败退出
    fi
    ```

总结

| 特性 | 函数返回值 | Shell脚本返回值 |
| :--- | :--- | :--- |
| 核心含义 | 函数内部的执行结果或状态 | 整个脚本的执行结果状态 |
| 主要方式 | `return` (状态码), `echo` (输出结果) | `exit` (状态码) |
| 数据类型 | `return`: 0-255 整数; `echo`: 任意字符串 | 0-255 整数 |
| 主要用途 | 函数内部逻辑控制、传递计算结果 | 告知调用者脚本执行结果 |
| 获取方式 | `return`: `$?`; `echo`: `$(function)` | `$?` |

因此，虽然它们都使用 `0` 表示成功、非 `0` 表示失败的约定，并且都通过 `$?` 来获取状态码，但函数返回值是函数级别的，而Shell脚本返回值是脚本级别的。函数的 `return` 值会成为脚本最后一条命令的退出状态，从而影响脚本的最终返回值。

## 009、shell脚本中的command -v的作用

在Shell脚本中，`command -v` 是一个用于检查指定命令是否存在并返回其路径或类型的内置命令。它通过搜索系统的 `PATH` 环境变量来定位命令，是判断软件是否安装或命令是否可用的推荐方式。

主要作用

1. 判断命令是否存在  
   如果命令存在，`command -v` 会输出该命令的完整路径（对于外部命令）或其类型（如内置命令、别名等）；如果不存在，则返回非零退出状态（通常为1）。  
   这使得它非常适合在脚本中用于条件判断，避免因命令缺失导致脚本失败。

   ```bash
   if command -v git >/dev/null 2>&1; then
       echo "Git 已安装"
   else
       echo "Git 未安装"
   fi
   ```

2. 忽略别名和函数，直接查找原始命令  
   如果脚本中定义了与系统命令同名的函数或别名，`command -v` 会绕过它们，直接查找系统原始命令，确保检测结果准确。

3. 获取命令的详细信息  
   与 `-v` 类似，`command -V`（大写）会提供更详细的描述，包括命令是别名、函数还是外部程序。

与其他命令的对比

| 命令 | 是否推荐 | 说明 |
| :--- | :--- | :--- |
| `command -v` | ✅ 强烈推荐 | POSIX 兼容，是内置命令，性能好，行为一致，是检测命令存在的标准方法。 |
| `type` | ✅ 推荐 | 功能类似，但会显示更多类型信息（如“别名”、“函数”），也适合用于脚本。 |
| `which` | ⚠️ 不推荐 | 是外部程序，依赖环境变量，行为可能因系统而异，不保证在所有Shell中可用。 |
| `hash` | ✅ 可用 | 检查命令是否在Shell哈希表中，适合检查已执行过的命令，但不适用于首次检测。 |

最佳实践

- 重定向输出：在脚本中使用 `>/dev/null 2>&1` 避免在终端输出干扰信息。
- 结合条件判断：常与 `if` 语句配合使用，实现健壮的依赖检查。
- 适用于自动化脚本：在安装脚本、配置脚本中广泛用于验证依赖项（如 `docker`、`python`、`nginx` 等）是否已安装。

> 示例：检查 `python3` 是否可用  
> ```bash
> if command -v python3 &> /dev/null; then
>     echo "Python 3 可用"
> else
>     echo "请安装 Python 3"
>     exit 1
> fi
> ```

综上，`command -v` 是Shell脚本中检测命令存在性的最可靠、最便携的方法。

## 010、shell脚本数组使用及计算数组长度

在Shell脚本中，数组是一种非常有用的数据结构，它可以存储一系列的值。Shell脚本（特别是Bash）提供了多种方式来创建、操作和计算数组的长度。

创建数组

在Bash中，你可以使用以下几种方式来创建数组：

1. 使用圆括号和空格
   ```bash
   array=(element1 element2 element3)
   ```

2. 逐个添加元素
   ```bash
   array[0]=element1
   array[1]=element2
   array[2]=element3
   ```

计算数组的长度

要计算数组的长度（即数组中的元素数量），你可以使用以下方法：

1. 使用`${#array[@]}`或`${#array[*]}`
   ```bash
   length=${#array[@]}
   echo $length  输出数组的长度
   ```
   或者
   ```bash
   length=${#array[*]}
   echo $length  输出数组的长度
   ```

遍历数组

你还可以通过循环来遍历数组中的所有元素：

1. 使用`for`循环
   ```bash
   for element in "${array[@]}"; do
       echo $element
   done
   ```

2. 使用`for`循环和索引
   ```bash
   for ((i=0; i<${array[@]}; i++)); do
       echo ${array[i]}
   done
   ```

示例脚本

下面是一个完整的示例脚本，展示了如何创建数组、计算其长度以及遍历数组：

```bash
#!/bin/bash

# 创建数组
array=(apple banana cherry)

# 计算数组长度
length=${#array[@]}
echo "Array length: $length"  # 输出数组的长度，应该是3

# 遍历数组
echo "Array elements:"
for element in "${array[@]}"; do
    echo $element
done
```

这个脚本首先创建了一个包含三个元素的数组，然后计算并输出了数组的长度，最后通过循环输出了数组中的每个元素。
