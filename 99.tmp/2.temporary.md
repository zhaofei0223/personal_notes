在Shell脚本中，括号（`()`、`(( ))`）和方括号（`[]`、`[[ ]]`）是功能完全不同的语法结构，它们分别用于命令执行/算术运算和条件测试。以下是它们的核心区别：

1. 小括号 `()` 与 双小括号 `(( ))`

- `()`（单小括号）：用于命令组或命令替换。
  - 命令组：括号内的命令会在一个子Shell中执行，不会影响当前Shell的变量环境。
    ```bash
    (a=10; echo "Inside: $a")  输出: Inside: 10
    echo "Outside: $a"         输出: Outside: （原变量a未被修改）
    ```
  - 命令替换：获取命令的输出结果。
    ```bash
    current_date=$(date)  将date命令的输出赋值给变量
    ```

- `(( ))`（双小括号）：用于算术运算和整数比较。
  - 支持C语言风格的算术表达式，如 `+`, `-`, `*`, `/`, `++`, `--`, `**`（幂）等。
  - 变量名不需要加 `$` 前缀。
  - 表达式结果为0时返回退出码1（假），非0时返回0（真）。
    ```bash
    a=5
    ((a++))                    a 变为 6
    if (( a > 3 )); then       直接比较，无需 -gt
        echo "a is greater than 3"
    fi
    echo $(( 16FF ))          输出: 255（十六进制转十进制）
    ```

2. 单方括号 `[]` 与 双方括号 `[[]]`

- `[]`（单方括号）：是 `test` 命令的别名，用于基本条件测试，遵循POSIX标准，兼容性好。
  - 字符串比较：使用 `=` 或 `!=`。
  - 整数比较：必须使用专用操作符，如 `-eq`, `-ne`, `-lt`, `-gt`, `-le`, `-ge`。不能使用 `<`, `>`。
  - 逻辑运算：使用 `-a`（与）、`-o`（或）。
  - 必须加空格，变量建议用引号包裹以防空值错误。
    ```bash
    if [ "$num" -eq 10 ]; then
        echo "num equals 10"
    fi
    if [ "$str" = "hello" ]; then
        echo "string is hello"
    fi
    ```

- `[[ ]]`（双方括号）：是Bash的扩展关键字，功能更强大、更安全。
  - 支持 `==`, `!=`, `<`, `>`, `<=`, `>=` 等直接比较运算符（无需 `-eq` 等）。
  - 支持模式匹配（通配符）和正则表达式（使用 `=~`）。
  - 不需要对变量加引号（但加了更安全）。
  - 支持 `&&`、`||` 等逻辑运算符，语法更直观。
    ```bash
    if [[ $num -eq 10 ]]; then           仍支持 -eq
        echo "num equals 10"
    fi
    if [[ $str  "hello" ]]; then       可用 ，无需引号
        echo "string is hello"
    fi
    if [[ $file == *.txt ]]; then        模式匹配：检查是否以 .txt 结尾
        echo "It's a text file"
    fi
    if [[ $text =~ ^[0-9]+$ ]]; then     正则匹配：检查是否为纯数字
        echo "It's a number"
    fi
    if [[ $a -gt 5 && $b -lt 10 ]]; then 可直接用 &&, ||
        echo "Condition met"
    fi
    ```

总结对比表

| 类型 | 名称 | 主要用途 | 关键特性 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| `()` | 小括号 | 命令组、命令替换 | 在子Shell中执行，不影响父Shell | `(cd /tmp; pwd)` |
| `(( ))` | 双小括号 | 算术运算、整数比较 | 支持C语言语法，变量无需 `$` | `(( x = 5 + 3 ))` |
| `[]` | 单方括号 | 基本条件测试 | POSIX标准，需用 `-eq` 等操作符 | `[ "$a" -eq 1 ]` |
| `[[ ]]` | 双方括号 | 增强条件测试 | 支持 `==`, `<`, `=~` 正则，更安全灵活 | `[[ $a > 1 && $b =~ ^[a-z]+$ ]]` |

推荐实践：在Bash脚本中，优先使用 `[[ ]]` 进行条件判断，使用 `(( ))` 进行算术运算，它们更强大、更不易出错。`[]` 和 `()` 保留用于需要最大兼容性的场景。
